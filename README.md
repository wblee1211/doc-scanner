# 문서 스캐너 (모바일 웹앱)

스마트폰 브라우저에서 문서를 촬영 → 테두리 자동 인식 → 원근 보정 → PDF로 저장하는 웹앱입니다.
빌드 과정 없이 정적 파일만으로 동작합니다.

## 파일 구성
- `index.html` — 화면 구조 (카메라 / 테두리 조정 / 보정 / 페이지 목록)
- `style.css` — 모바일 최적화 다크 UI
- `scanner.js` — OpenCV.js 처리: 문서 사각형 검출, Perspective Transform, 문서 정리 필터(컬러·흑백·그레이)
- `app.js` — 카메라(getUserMedia), 모서리 드래그 UI, 페이지 관리, PDF 생성(jsPDF)
- `ocr.js` — Tesseract.js 글자 인식(한국어+영어), 검색 가능한 PDF용 숨은 글자 레이어

## 실행 방법
스마트폰 브라우저는 **HTTPS 주소에서만** 카메라 미리보기를 허용합니다.

1. PC에서 테스트: `python3 -m http.server 8000` 후 http://localhost:8000
2. 폰에서 사용: 폴더를 HTTPS 정적 호스팅에 올리세요.
   - Netlify Drop(https://app.netlify.com/drop)에 폴더를 끌어다 놓기, 또는 GitHub Pages
   - 임시 테스트: 로컬 서버 실행 후 `npx localtunnel --port 8000` 으로 받은 https 주소 접속

HTTPS가 아니면 "사진 촬영 / 선택" 버튼으로 폰 기본 카메라 앱을 대신 사용할 수 있습니다.

## 사용 흐름
**최고 화질 팁**: 오른쪽 위 **고화질** 버튼(또는 폰 카메라로 찍은 뒤 갤러리 버튼으로 불러오기)을 쓰면
폰 기본 카메라의 전체 해상도·자동 초점·HDR이 적용되어 브라우저 미리보기 촬영보다 훨씬 선명합니다.

1. 카메라 화면: 셔터 위에서 **컬러 / 흑백** 스캔 모드 선택(선택은 기억됨) → 문서가 인식되면 파란 테두리가 표시됨 → 셔터
   - 안드로이드 Chrome에서는 미리보기보다 높은 해상도의 사진으로 촬영
2. 테두리 조정: 모서리/변 핸들을 드래그 (드래그 중 돋보기 표시), 자동 감지·전체 선택·회전
3. 보정: 스캔 모드에 맞는 필터가 자동 적용 → 필요하면 바꾸고 회전 → 저장
   - 컬러 문서: 그림자·조명 얼룩·종이 누런기를 고르게 하고 종이를 흰색으로 — 원본 색과 대비는 최대한 유지
   - 흑백 문서: 글자와 배경을 완전한 흑/백으로 분리, 작은 점 노이즈 제거
   - 그레이 / 원본
4. 오른쪽 아래 썸네일 → 페이지 순서 변경·삭제·재편집 → PDF 다운로드 또는 공유
5. **글자 인식**: 페이지 목록에서 "글자 인식" → 인식된 텍스트를 고쳐서 복사하거나 .txt로 저장
   - 인식한 뒤 PDF를 받으면 **검색·복사 가능한 PDF**로 저장됩니다 (이미지 위에 보이지 않는 글자를 겹쳐 넣음)
   - 처음 한 번 인식 엔진·한국어 데이터(약 9MB)와 한글 글꼴(약 2MB)을 내려받습니다
   - 인식은 폰 안에서만 처리되어 이미지가 외부 서버로 전송되지 않습니다
   - 선명하고 글자가 큰 사진일수록 정확합니다 (고화질 버튼 권장). 표·네모 칸이 많은 학습지는 오류가 생길 수 있어요

참고: OpenCV.js(약 10MB)는 첫 실행 시 CDN에서 내려받고 이후 브라우저 캐시를 사용합니다.
스캔한 페이지는 메모리에만 있으므로 새로고침하면 사라집니다.

## 업데이트 시 주의
파일을 고치면 `index.html`의 `style.css?v=4`, `scanner.js?v=4`, `ocr.js?v=4`, `app.js?v=4` 숫자를 하나 올려주세요.
그래야 폰 브라우저가 예전 파일을 캐시에서 쓰지 않습니다.
